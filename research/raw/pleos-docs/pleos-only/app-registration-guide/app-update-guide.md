# 앱 업데이트 가이드
Pleos App Market은 앱 자동 업데이트를 지원하지 않습니다. 사용자가 직접 업데이트를 진행할 수 있도록 앱에서 업데이트 시퀀스를 제공·가이드해야 합니다.

본 가이드는 업데이트 절차(버전 확인 → 안내 팝업 → 앱 마켓 이동 → 업데이트 실행)와 그 과정에서 앱 개발사가 구현해야 할 항목과 앱 마켓이 제공하는 기능을 구분해 안내합니다.

## 관련 정책​

앱 버전 변경 의무와 심사 반려 기준은 앱 버전 관리 정책에서 확인할 수 있습니다.

## 앱 업데이트 프로세스​

- 앱이 실행되면 최신 버전인지 확인합니다. 버전 확인은 앱 개발사에서 구현합니다.

- 최신 버전이 아닐 경우, 업데이트 안내 팝업을 출력합니다.

- 안내 메시지는 `최신 버전이 존재합니다. 업데이트를 위해 페이지를 이동할까요? (Yes, No)` 이며, 이 부분은 앱 개발사가 구현합니다.

- 2의 안내 팝업창에서 Yes를 선택한 경우 앱 상세 페이지로 이동합니다.

- 앱 상세 페이지 경로는 `market://detail?package={페키지명}` 이며, 이 부분은 앱 개발사가 구현합니다.

- 3번 절차 후 앱 마켓은 로그인 여부를 확인하여 다음을 수행합니다.

- 로그인 상태가 아닌 경우, 로그인 창을 출력합니다. 사용자가 로그인을 완료하면 마지막 사용 페이지로 이동시키거나 앱 마켓 홈으로 이동시키고 업데이트 프로세스를 종료합니다.

- 로그인 상태인 경우, 앱 상세 페이지로 이동시킵니다. 사용자가 [업데이트] 버튼을 누르면 업데이트가 진행됩니다.

- 2의 안내 팝업창에서 No를 선택한 경우 업데이트를 진행하지 않습니다. 이때 개발사 정책에 따라 앱 사용을 유지하거나 앱 사용을 종료합니다. 앱 개발사에서 구현합니다.

- 1에서 최신 버전일 경우에는 앱 실행을 유지하고 업데이트 프로세스를 종료합니다.

## 앱 개발사 구현 항목​

| | 항목 | 개발사 구현 | 앱 마켓 제공
| | 버전 체크 | ✅ | ⛔  (SDK 제공 차후 고려)
| | 업데이트 안내 메시지 출력 | ✅ | ⛔
| | 업데이트 Yes 선택 시 이동 경로 제공 | ✅ | ⛔
| | 앱 상세 페이지 이동 시 로그인 여부 확인 및 처리 | ⛔ | ✅
| | 업데이트 No 선택 시 조치 | ✅ | ⛔
