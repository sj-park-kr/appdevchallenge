## 5. 눈여겨볼 두 개

### W1 고속도로 위기 가디언 — "차가 그 순간을 알아챈다"
- **장면**: 고속도로에서 차가 서고 비상등이 켜지면 → "트렁크를 여세요" → 트렁크 열림 감지 → "모두 가드레일 밖으로" → **뒷좌석 탑승 센서가 아직 사람을 감지하면 "뒷좌석에 아직 누가 있어요"** → 정확한 위치(노선·방향)로 원탭 신고
- **차라서 되는 것**: 속도 0, 비상등, 트렁크·도어 열림, 좌석 탑승은 모두 차만 아는 정보. 폰 앱은 "지금 위기인지" 자체를 모름
- **근거**: 치사율 54.3%, 도로공사가 이미 같은 순서(비트박스)를 캠페인 중 → **공공기관 행동요령을 차량이 실행**하는 구조라 설득력이 큼
- **약점**: 1년에 한 번도 안 쓸 수 있음 → 사업성 약함. 보험사 긴급출동 연계나 "차량 기본 탑재 제안"으로 풀어야 함
- **PT**: Virtual Console에서 속도 0 → 비상등 → 트렁크 → 좌석 탑승 순서로 조작하면 앱이 단계별로 반응. 5분 안에 긴장감 있는 시연 가능

### W2 와이퍼 날씨 지도 — "차가 움직이는 기상 관측소"
- **장면**: 앞쪽 경로의 Pleos 차들이 와이퍼를 최고 단계로 켜기 시작 → "5km 앞 폭우, 감속하세요" + 지자체·기상 데이터로 판매
- **근거**: 미시간대 연구에서 와이퍼 데이터가 레이더·우량계보다 강우 여부를 잘 맞힘. 도요타·웨더뉴스가 상용화를 시도함
- **약점**: 차가 많아야 의미가 있음(초기엔 데이터 공백). 위치·차량 데이터를 서버로 모으는 구조라 **개인정보 심사**가 가장 큰 관문. 현대차가 직접 할 법한 사업이라 "왜 외부 앱이?"라는 질문을 받을 수 있음
- **PT**: 가상 차량 여러 대 시뮬레이션으로 지도가 실시간으로 물드는 장면
