### 거리 측정 방식
- 블루투스 신호, 휴대폰 배터리 충전 감지, 카택스 비콘(USB 연결 장치)으로 운행 시작·종료를 감지하고, 조건 충족 후 속도가 감지되면 자동 기록. 전용 GPS 단말기 없이 앱만으로 작성 가능 [요약: cartax.biz 홈 + 앱스토어 소개 + 검색 스니펫]
- GPS 수신이 안 되는 지하주차장·음영지역에서는 작동 안 함 [원문: 앱스토어 소개 문구]
- 거리 산정이 GPS 기반인지(위치 좌표 적산) 여부는 **명시 안 됨**. 앱은 "항상 허용" 위치 권한을 요구하며 배터리 소모 불만이 있음 [요약: 앱스토어 리뷰]

### 운전자 식별
- 공식 페이지에서 **언급 없음**. 검색 스니펫에 "카택스 비콘을 쓰면 운전자를 자동 인식할 수 있다"는 설명이 있으나 원문 확인은 못 함 [요약: 검색 스니펫, 블로그 성격 페이지]. 비콘 방식은 운전자 개인이 아니라 차량 또는 기기 단위 식별에 가까울 가능성이 있음(추정).

### 과태료 관리
- **언급 없음.** 과태료 조회·운전자 매칭 기능은 공식 페이지와 앱스토어 소개 모두에서 확인되지 않음 [요약]

### 차량 인수인계·반납 점검
- 점검·인수인계 기능 **언급 없음**. 차량 예약과 일정 공유 기능은 있음 [요약: cartax.biz 홈]

### Samsara
- **운전자 행태 점수**: Driver Safety Score와 이를 구성하는 이벤트(급제동, 과속 등)를 운전자 앱에서 확인. 관리자는 Safety Leaderboard를 켜고 익명 처리 여부를 선택 가능. 운전자는 안전 이벤트를 검토·확인하고 짧은 교육 모듈을 수행 [요약: kb.samsara.com 스니펫, App Store 앱 설명]
- **차량 상태·정비 예측(고장 알림)**: Preventive Maintenance. 엔진 고장 알림을 켜면 고장 발생 시 실시간 알림. 고장코드를 사람이 읽을 수 있는 설명으로 바꾸고 즉시 조치 여부를 구분. 정비 일정(주행거리·기간 주기) 등록, Resolve·Snooze·Ignore, 정비 로그 기록. 원문은 "추가 비용 없이 모든 Samsara 플릿 고객에게 제공" [원문 요약: samsara.com 블로그. 단, 게시일 2016년 10월이라 현행 정책 확인 필요]. 예측(predictive)이라기보다 고장코드 기반 실시간 알림에 가까움
- **차량 점검 (DVIR, 운행 전후 점검)**: 운전자가 앱에서 디지털 점검 보고서 제출. 대시보드에서 정비 기록과 함께 확인. 정비사가 수리 내용을 기록하고 서명해 다음 운전자가 검증. 관리자가 수동으로 DVIR 추가 가능. 데이터 보관 기간 설정 가능 [요약: samsara.com/fleet/connected-driver/dvir 스니펫, kb.samsara.com]
- **과태료(ticket) 관리**: 검색으로 확인 안 됨. 드라이버 배정(Driver Assignment)은 차량과 운전자를 연결하는 기능으로 확인됨. 배정 소스 우선순위: 안전 인박스 수동 변경 > API > 타코그래프 > HOS·운전자 앱 > RFID·QR·블루투스·카메라 ID 등 [요약: samsara.com 및 developers.samsara.com 스니펫]. 과태료 자동 귀속 기능의 존재는 확인되지 않음
- **통행료**: 확인 안 됨
- **가격**: 공개 가격 없음. 제3자 추정 소프트웨어 월 약 27~33달러/대(기본, 3년 약정), 부가 기능 포함 시 40~60달러/대, 하드웨어 99~148달러/대 [요약: 제3자 리뷰 사이트. 공식 아님]
