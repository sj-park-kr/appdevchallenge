# 현대자동차그룹 차량용 앱 개발 공모전 준비

Pleos Connect(현대차그룹 인포테인먼트)용 차량 앱 공모전 준비 저장소입니다. 지금은 **아이디어 조사·선정 단계**이고, 앱 코드는 아직 없습니다.

- 접수 마감: **2026-11-15(일) 23:59** (이메일 접수)
- 심사 기준: 차량특화성 · 창의성 · 기술 활용성(Pleos SDK) · 사업성 + 개발 산출물 가산점
- 사용 가능한 SDK: **Vehicle State, NaviHelper** (나머지 4개는 준비 중)

## 현재 상태
