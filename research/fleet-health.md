# 선정안 근거 조사: 법인 차량 건강 기록부 (2026-10-23)

> 선정안([ideas.md](ideas.md) 맨 위)의 근거를 서브 에이전트 5개(Haiku)로 조사한 결과입니다. 원본(출처 URL 포함): `research/raw/fleet/`
> 인용 대부분은 **[요약]**(WebFetch·검색 요약)입니다. 메인이 5개를 원문과 대조 → 4개 일치(프레시안 46%, 서울시의회 감사, fueleconomy.gov, 클리앙), 1개는 사이트 차단으로 확인 못 함(Discovery 잔존가 15%).

## 1. 결론 먼저
| 가설 | 근거 강도 | 판단 |
|---|---|---|
| 운행일지 자동화 수요 | **강함**. 단, 이미 상품화됨 | 기본 기능. 이것만으로는 차별 불가 |
| **운행일지가 거짓이거나 빠진다** (감사 지적) | **강함** — 공공기관 감사 실명 사례 다수 | ⬆ **새 핵심 후보**: "차가 직접 쓴, 고칠 수 없는 일지" |
| 과태료가 회사로 오고 운전자를 찾아야 함 | 중간 — 구조는 확인, 관리자 불편 원문은 없음 | 유지 (기능 단순, 경쟁사에 없음) |
| 공용차 인수인계 갈등 (기름·경고등) | **약함** — 국내 자료 0건 | ⬇ 가설로만. 인터뷰로 확인 필요 |
| 운전 습관 → 부품 수명 → 잔존가치 | **약함** — 독립 연구 없음, 기업 자료뿐 | ⬇ 로드맵(확장)으로 |

→ **제안: 차별점의 중심을 "자산 가치"에서 "기록의 신뢰성(감사 대응)"으로 옮긴다.** 상태 리포트는 로드맵으로.

## 2. 영역별 근거

### 2-1. 운행일지는 거짓이거나 빠진다 (공공기관 감사)
- 영천시 노조 관용차: 일지 16회 외 약 14회 추가 운행 → **"46%의 운행기록이 누락"**, 일지와 실제가 다르면 "허위공문서 작성" 논란 ([프레시안](https://www.pressian.com/pages/articles/2023090414051850921), 2023.09, 원문 대조 ✅)
- 서울소방본부 관용차 302대, 2021~2023.09 사용 80,024건: "목적지가 게임장, 주점, 노래방 등인데 용무는 '기타'", "목적지명이 모두 숫자 또는 0", 출퇴근 불가 차량이 '출퇴근'으로 기재 ([서울시의회 행정사무감사 보도](https://www.youthassembly.kr/news/746208), 2023.11, 원문 대조 ✅)
- 경기복지재단: "운행 일지가 없거나 미등록", "경유차인데 주유 기록에는 무연휘발유" ([뉴스서울](https://newsseoul.co.kr/news/view/179589967381382), 2022.11)
- EBS 이사장 차량: 일지가 "본사-서초동-시내일원-서초동-본사"로 형식적 기재, 비용의 약 91%가 사적 용도로 판단(감사원) ([기자협회보](https://www.journalist.or.kr/m/m_article.html?no=34761), 2014)
- 민간: 중소기업 대표 "개인적인 용도로 타지 말라고 하지는 못하고 있습니다", 일지 의무화 제안에 기록 조작 가능성·GPS 개인정보 우려 ([클리앙](https://www.clien.net/service/board/cm_car/17165976), 2022, 원문 대조 ✅)
- 국세청장: 법인 명의 슈퍼카 사적 사용은 "명백한 탈세" ([위키트리](https://www.wikitree.co.kr/articles/1138275), 2026.05)

**→ 감사가 지적하는 항목(목적지·용무·주행거리·주유)이 차량 데이터로 그대로 채워지는 항목입니다.** 목적지=NaviHelper, 주행거리=계기판, 주유=연료량 상승.

### 2-2. 과태료와 운전자
- 무인단속 과태료는 **차량 소유자(회사)** 에게, 현장 단속 범칙금·벌점은 운전자에게 → 회사가 운전자를 특정해야 함. 연예인 소속사가 과태료를 즉시 대신 납부한 사례 ([데일리안](https://www.dailian.co.kr/news/view/1647881/), 2026.05)
- 고용주가 운전자를 밝히면 과태료 대신 범칙금 대상이라는 법제처 해석(12-0035, **2012년**, 현행 확인 필요)
- 관리자가 "그 시각 누가 탔나"를 찾느라 힘들다는 원문은 **못 찾음** → 인터뷰로 확인 필요

### 2-3. 인수인계 갈등
- 국내 자료 0건. 해외 리스 반납 기준에 "연료 1/4 이상", "경고등 점등 시 반납 실패 £144" 정도 (Alphabet 영국, [요약])
- → 가설로만 남김

### 2-4. 운전 습관 → 부품·잔존가치
- 확실한 것: 공격적 운전은 연비를 고속 15~30%, 정체 구간 10~40% 떨어뜨림 ([fueleconomy.gov](https://www.fueleconomy.gov/feg/driveHabits.jsp), 정부, 원문 대조 ✅) — **연비 효과이지 부품 수명 효과가 아님**
- 브레이크·타이어: 방향성만 있음. 운전 습관으로 패드 수명이 25% 차이 난다는 부품사 인터뷰가 있으나 원문 확인 못 함(Alcon). 블로그 수치(20~50%)는 출처가 없어 인용 금지
- 정비 이력의 가치: Carfax 리포트를 붙여 팔면 대당 평균 $300 더 받았다는 GE Fleet 자체 발표 등 **기업 자료뿐**
- **선례**: Discovery Insure **Vitality Car Rating**(남아공, 2025). 텔레매틱스 운전 행태·수리 이력으로 차에 등급을 매기고, 참여 딜러에서 팔면 잔존가가 2~15% 오른다고 주장(기업 자료, 원문 차단). → 같은 발상이 이미 있음 + 수요의 근거
- 리스 반납: 국내 리스사 공식 평가 기준은 공개된 게 없음. 사람이 감정하고, 텔레매틱스로 반납 정산을 한 실제 사례도 못 찾음
- 한국 성능·상태점검기록부에는 운전 습관 항목이 없음

### 2-5. 법령 (2차 자료, 원문 미대조)
- 1,500만원(운행기록이 없을 때 연 한도, 감가상각비 800만원 포함), 800만원(감가상각비 연 한도), 20만원(자가운전보조금 월 비과세): 2차 자료 다수 일치
- 운행기록 고시: **국세청고시 제2025-8호** (2025.4.1 시행). 기재 항목 원문은 확인 못 함
- 2026 세제개편안(2026.8.3 발표, 국회 심의 전): 감가상각 한도를 전기·수소차 1,000만원, 그 외 700만원으로 변경 (2027년 취득분부터)
- 부동산임대업 500만원 한도는 근거를 못 찾음 → [voices.md](voices.md)의 해당 서술은 확인 필요

## 4. 구체화 제안 (사용자 확인 필요)
**한 줄**: "차가 직접 쓰는, 고칠 수 없는 법인 차량 일지" — 감사·세무에 바로 내는 운행기록 + 과태료 운전자 찾기

| 우선순위 | 기능 | 감사·불편 근거 | SDK |
|---|---|---|---|
| 1 | 자동 운행기록: 시작·끝 계기판 거리, 실제 목적지, 시간 | 46% 누락, "본사-시내일원" 형식 기재 | `getCurrentDistanceDriven`, `getDestinationInfo`, `getRecentDestinationInfo`, 속도·기어(AAOS) |
| 2 | 용무 자동 채움: 거래처 즐겨찾기 도착=업무, 집↔회사=출퇴근, 근무 외 시간·유흥 업종 목적지=확인 요청 | 목적지 게임장인데 용무 '기타', 출퇴근 허위 | `getBookmarkInfo`, 위치, 시각 |
| 3 | 주유 자동 감지 → 주유 기록과 대조 | 경유차에 휘발유 기록, 주유-운행일 불일치 | `getFuelPercent` |

## 4-1. 시장 규모 (첫 숫자)

## 5. 아직 확인할 것
- 관리자 인터뷰: 과태료 운전자 찾기, 인수인계 갈등이 실제로 큰지 (온라인에 원문 없음)
- 고객을 누구로 할지: 공공기관(감사 근거 강함, 조달 장벽) vs 민간 법인(세무)
- 법령 원문 대조 (law.go.kr 본문이 자동으로 안 열림 → 직접 확인)
- U+차량관제의 "과태료 관리"가 운전자 매칭인지
- 에뮬레이터: 계기판 거리·목적지·연료량이 실제로 읽히는지, 운전자 선택 UI가 주행 중 제한에 걸리지 않는지
