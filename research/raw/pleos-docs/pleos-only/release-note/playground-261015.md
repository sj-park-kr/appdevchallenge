# Pleos Playground 개편

- Release version: Pleos Playground v2.6.0

- Release date: 2026년 10월 19일

이번 업데이트에서는 Pleos Playground의 사이트 구조와 탐색 기능을 개편하고 문서 검색 기능을 추가하여 개발자 경험을 개선했습니다.
사이트와 개발자 가이드를 앱 개발 흐름에 맞춰 재구성하여 개발 단계별로 필요한 정보와 자료를 더 쉽게 찾을 수 있습니다.

## New Features​

### 개발자 여정 가이드​

초기 설정부터 개발 및 검증까지 Pleos 앱 개발의 전체 과정을 단계별로 확인할 수 있습니다.
Pleos Playground 메뉴에서 Discover > Developer Journey를 확인하세요.

### 문서 검색 기능​

Pleos Playground 상단의 검색 아이콘을 통해 문서를 검색할 수 있습니다.

## Improvements​

### Pleos Connect 개발자 가이드​

Pleos Playground의 개발자 여정에 맞춰 Pleos Connect 개발자 가이드를 재구성했습니다.
앱 개발 시작부터 기획·설계, 개발·연동, 테스트, 앱 등록까지 개발 과정에 따라 필요한 문서를 더 쉽게 찾을 수 있습니다.

Pleos Connect 앱 개발 시작하기

개편된 구조에서 주요 가이드를 다음과 같이 확인할 수 있습니다.

- Pleos Connect Virtual Console 가이드

- Pleos Connect Virtual Console의 설정 및 사용 방법을 안내합니다.

- Pleos Connect Virtual Console 셋업 가이드

- 폼 팩터 테스트 가이드

- Pleos Connect Emulator에서 다양한 디스플레이 해상도와 방향에 따라 앱 화면이 정상적으로 표시되는지 테스트하는 방법을 안내합니다.

- 폼 팩터 테스트 가이드

- Vehicle SDK Sample App 사용 가이드

- 차량 기능의 지원 범위 확인, 현재 상태 조회, 상태 변경 요청, 변경 알림 구독 등 Vehicle SDK의 사용 흐름을 익힐 수 있는 샘플 앱의 사용 방법을 안내합니다.

- Vehicle SDK Sample App 사용 가이드

## Removed Features​

### LLM SDK​

LLM SDK 제공을 종료합니다. Gleo AI와의 연동이 필요한 경우 Gleo Interface를 이용할 수 있습니다.
