## SDK 변경 상세​

### Vehicle SDK v2.3.2​

Vehicle SDK v2.3.2의 주요 변경 사항입니다. 전체 변경사항 중 주요 항목을 중심으로 정리했습니다.

#### Breaking change​

| | 대상 API | 변경 내용 | 필요한 대응
| | CruiseControl | 기존 상수 제거, 상태 구성 변경
OFF, READY, ACTIVE 제거. 최신 상태는 OTHER, ENABLED, ACTIVATED, USER_OVERRIDE, SUSPENDED, FORCED_DEACTIVATION_WARNING | 기존 상수 참조·상태 분기·저장된 enum 이름 확인 및 수정. 단순 일대일 이름 변경으로 처리하지 않음
| | checkHvacFanSpeedCapabilities | 콜백 값 타입 변경
Map<SeatArea, List<Int>> → Map<SeatArea, AreaBounds<Int>> | 기존 List<Int> 반환 계약은 유지되지 않으므로 목록 처리 코드를 최소·최대 범위 처리로 수정
| | FanDirectionType | enum 확장, 순서 변경
기존 3개에서 UNKNOWN과 복합 풍향을 포함한 8개로 확장 | 모든 값을 나열한 when 식에 새 상태 처리. ordinal 저장 시 마이그레이션 필요: FACE 0 → 1, FLOOR 1 → 2, DEFROST 2 → 4
| | DoorArea, MirrorArea, SeatArea, TurnSignalArea, WheelArea, WindowArea | 동등성 변경
내용 기반 equals·hashCode 추가로 같은 순서의 영역 값을 가진 별도 객체가 동등하게 처리됨 | 객체마다 다른 키라고 가정한 Map·Set 및 동등성 비교 로직 확인

#### New API​

| | 기능 | 대표 API | 추가 내용
| | Capability 조회 | checkVINInfoCapabilities
checkSmartGlassLevelCapabilities 등 | 차량 기능 지원 여부와 접근 속성 확인
| | 상태 조회·구독 | getCurrentEvEfficiency
registerEvBatteryStateOfCharge
getCurrentSmartGlassLevel 등 | EV/Fuel 효율, 배터리 충전율, 연료량, ETCS 음성 안내 볼륨, Smart Glass level 조회·구독
| | 차량 정보 조회 | getVINInfo | VIN 조회
| | SDK 모델 | CapabilityConfig, TripStatistics, TelltaleData, Telltales | Vehicle SDK에서 신규 제공되는 모델

#### Changed API​

| | 대상 API | 변경 내용 | 전환 안내
| | checkDoorLockCapabilities
checkWindowPositionCapabilities 등 기존 Capability API | 오버로드 추가 · 이전 콜백 형태 deprecated
CapabilityConfig 등을 함께 전달하는 새 콜백 제공 | 새 오버로드 사용 권장. WARNING 수준의 deprecation 자체는 기존 선언 삭제가 아님. 단, checkHvacFanSpeedCapabilities는 Breaking change의 값 타입 변경도 함께 대응
| | registerHvacTemperature
registerHvacTemperatureCurrent
및 대응하는 해제 함수 | 오버로드 추가
HvacTemperatureValueListener를 받는 형태 추가 | 기존 HvacTemperatureListener 형태는 유지되므로 필요 시 전환
| | EvBatteryLevelListener
EvChargePortOpenListener
RangeRemainingListener | 문서 숨김 | 리스너 타입과 콜백 호출은 유지되며, 실제 API 삭제와 구분

#### Deprecated API​

| | 대상 API | 변경 내용 | 전환 안내
| | getCRNInfo
checkCRNInfoCapabilities | Deprecated | 각각 getVINInfo, checkVINInfoCapabilities로 전환 권장
| | checkWheelAreaCapabilities | Deprecated | CapabilityConfig와 List<WheelArea>를 함께 받는 checkLowTirePressureCapabilities로 전환 권장

#### Shutdown API​

| | 대상 API | 변경 내용 | 필요한 대응
| | getHvacTemperatureValueSuggestion | 삭제
메서드 제거 | 해당 메서드를 사용하는 코드 수정
| | VehicleSpeedListener | 삭제
리스너와 onSpeedUpdated 제거 | 해당 타입·콜백을 사용하는 코드 수정

### NaviHelper v3.0.5​

- Breaking change

- 내비 상태 콜백 인자 타입 및 상태 값 변경(onNavigationStatus: RouteDriving → NavigationStatus)

- 데이터 모델 생성자의 좌표 인자 순서 변경(longitude, latitude → latitude, longitude; BookmarkInfo, CurrentLocationInfo, DestinationInfo, RecentDestinationInfo, RequestWaypointInfo, RouteInfo, WaypointInfo)

- 목적지/경유지 데이터 필드명 변경(DestinationInfo, WaypointInfo: totalDistance/totalTime → remainDistance/remainTime)

- New API

- 경로/화면 요청 API 추가(requestTrip, requestRouteWithWaypoints, requestNavigationScreen)

- 초기화 결과 콜백 지원 추가(initialize(onConnected, onFailed))

- 내비 이벤트 리스너 확장(onCautionPointInfo, onRoutingCompleted, onTripInfo)

- Changed API

- 내비 데이터 모델 필드 확장(POI provider, 좌표/거리, Trip/Traffic/Waypoint 관련 정보)

- 상수/Enum 추가 및 변경(CameraType, CautionPointType, NavigationStatus, RoutePointType)

- Deprecated API

- 경로 탐색 완료 콜백 사용 중단 예정(onRouteEnded → onRoutingCompleted 사용 권장)

- Shutdown API

- 사용자 정의 경로 결과 타입/콜백 제거(FindRouteResult, onUserDefinedRoute)

- 구간 단속 카메라 Enum 값 세분화(CameraType.SPEED_CAMERA_SECTION 제거 → SPEED_CAMERA_SECTION_START, SECTION_SPEED_ALERT, SPEED_CAMERA_SECTION_END)
