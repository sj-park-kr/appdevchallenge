## 1. 심사 항목별 체크리스트

### 1-1. 등록 정보 (review-app-registration-info.md)

- [ ] 기본 정보는 정확하게 입력: "기본 정보는 정확하게 입력되어야 합니다."
- [ ] 욕설·폭력·선정·불법 묘사 금지: "욕설이나 폭언, 폭력적인 묘사 직/간접적으로 선정적인 묘사 범죄 또는 불법(약물, 테러 등)행위 등을 묘사하여서는 안 됩니다."
- [ ] 실적·순위·매출 등 사실 확인 어려운 내용 금지: "App Market 실적, 순위, 매출 등 사실 확인이 힘든 내용이 포함되어서는 안 됩니다."
- [ ] 텍스트 이모티콘·반복 특수문자 금지
- [ ] 앱 제목 30자(영문 기준) 이하: "앱 제목은 30자(영문 기준)를 초과해서는 안 됩니다."
- [ ] 서비스 대상 국가별 언어로 된 메타데이터 모두 제출
- [ ] 카테고리: 적합한 것 선택 (부적합 시 임의 변경 가능)
- [ ] 앱 아이콘: PNG 또는 JPEG, 용량 최대 1 MB, 해상도 512 x 512 px
- [ ] 앱 이미지: 최소 2장, 최대 8장. 1장당 최대 8 MB, PNG 또는 JPEG. 해상도 2560 x 1380 / 1700 x 1212 / 840 x 1212 px (문서 내 표기 불일치는 2-4절 참고). 예시: "기능 사용 전 / 기능 사용 후 / 앱만의 기능을 사용하는 화면 등"
- [ ] 이미지가 실제 앱과 다르면 거부: "제출된 아이콘과 이미지가 실제 앱과 다른 경우, 심사 거부될 수 있습니다."
- [ ] 패키지 파일은 APK: "패키지 파일은 APK 파일로 제출해야 합니다." 압축 후 최대 600 MB 미만: "사용자가 다운로드할 압축된 최대 파일 크기는 600MB보다 작아야 합니다."
- [ ] 연령 등급: "앱의 연령 등급은 콘텐츠에 적절한 수준으로 적용되어야 합니다." 등급 설문에 정직하게 답변
- [ ] 개인정보 처리 과정·접근 권한·위치정보·광고성 정보 전송 여부를 "투명하고 정직하게" 설정
- [ ] 개인정보처리방침 등록 (앱 전용 방침이 없으면 회사 공통 방침 가능)
- [ ] 위치정보 사용 시 "위치정보 이용약관 및 기타 정보 처리방침"도 함께 제출: "앱에서 위치정보 서비스를 사용하는 경우, '위치정보 이용약관 및 기타 정보 처리방침'을 함께 제출해야 합니다."
- [ ] 로그인 필요 시 심사용 계정 제출: "개발자를 위한 관리자 계정이 아닌, 실제 사용자 기준의 계정을 전달해야 합니다." (로그인 없는 앱이면 해당 없음이라고 원문에 명시되어 있지는 않음)
- [ ] 증빙 서류: 지식재산권·정부 위임·도메인 증빙 등은 해당될 때만 (해당 여부는 문서에 판단 기준 없음)
- [ ] 개발자 적법성 증명: "앱의 개발자와 관리자가 적법한지 증명할 수 있어야 합니다."
- [ ] 메타데이터 악용 적발 시 즉시 제외 및 영구 제재: "메타데이터를 악용하여 사용자를 속이는 행동이 확인되는 경우, 해당 앱을 즉시 제외하고 영구적으로 제재할 수 있습니다."

### 1-2. 콘텐츠 안전 (review-content-safety.md)

- [ ] 과도한 선정·폭력·불쾌감 콘텐츠 금지: "제출된 앱 내에는 과도하게 선정적이거나 폭력적인 묘사 또는 불쾌감을 조성할 수 있는 콘텐츠가 포함되어선 안 됩니다."
- [ ] 안전을 저해하는 콘텐츠 금지: "음주 운전, 과속, 신호 위반 등 운전자의 안전을 저해하는 행동을 권유, 조장, 홍보, 미화하는 콘텐츠가 포함되어서는 안 됩니다."
- [ ] 아동이 차량 밖으로 신체 일부를 내밀도록 유도하는 콘텐츠 거부
- [ ] 차별적 내용 금지 (인종·종교·성별 등)
- [ ] 민감한 내용 (재난·사고·전쟁 등으로 이익을 얻는 내용) 금지
- [ ] 사용자 제작 콘텐츠·AI 생성 콘텐츠 사용 시 필터링 및 신고 기능 필요: "이러한 콘텐츠를 사용하는 앱은 부적절한 콘텐츠를 필터링해야 하며, 사용자가 이러한 콘텐츠가 존재하는 것을 개발자에게 알릴 수 있는 신고 기능을 포함해야 합니다." (우리 앱은 사용자 제작 콘텐츠에 해당하는지 판단 기준 문서에 없음)
- [ ] 지식재산권 침해 금지
- [ ] 미성년자 보호: "기본적으로 별도의 인증 없이도 볼 수 있는 앱의 화면 및 미리보기, 썸네일, 인앱 스크린샷 및 상품의 사진에는 '전체 이용가' 등급의 콘텐츠만 노출되어야 합니다."
- [ ] 연령 등급은 등급 조사 설문 응답 기준, 정직하게 답변

### 1-3. 운전자 주의 분산 (review-driver-distraction-elements.md)

- [ ] Pleos Connect UI Design Guide 사전 확인 필수: "Pleos Connect의 Pleos Connect UI Design Guide 가이드를 반드시 사전 확인하시고 개발된 앱을 제출하시기 바랍니다."
- [ ] 가이드 준수가 위험의 완전 배제를 뜻하지 않으며, 추가 위험 판단 시 등록 거부 가능
- [ ] 아래 항목은 **미디어 앱(동영상·게임·브라우저)** 에 적용되는 조항. 우리 앱 해당 여부는 문서에 판단 기준 없음
  - 주행 중 실행·사용 불가: "모든 미디어 앱은 운전 중에 실행하거나, 사용할 수 없어야 합니다."
  - 운전 시작 시 UI 숨김
  - 헤드업 알림 금지 (운전 무관 알림 불가)
  - 백그라운드 복귀 시 상태 복원
- [ ] 기타 조항(미디어가 아닌 앱)은 문서에 없음. 운전 중 입력·화면 조작 제한의 구체 수치는 UI Design Guide 참조 (문서에 없음, 원문 미수집)

### 1-4. 기능·성능·안정성 (review-functionality-performance-stability.md)

- [ ] 설치·삭제 오류 없음. 삭제 시 아이콘·저장 공간 잔존 파일 없어야 함: "앱을 삭제하였으나, 아이콘 또는 저장 공간에 관련 파일이 남아 있습니다."
- [ ] 실행 시 강제 종료·하드웨어 재시작 없음
- [ ] 기능 사용 시 화면 멈춤, 기능 미동작, 터치 미인식 없음
- [ ] 임시 파일·더미 데이터·임시 콘텐츠 없음: "앱 내에는 테스트를 위한 더미 데이터나 임시 파일이 존재하면 안 됩니다."
- [ ] 화질 저하(왜곡·흐림·모자이크) 없음, 디스플레이 안전 영역 준수
- [ ] 앱 유형(카테고리)에 벗어난 기능 금지: "앱 유형(카테고리)에 벗어나는 기능이 포함되거나 서비스 내용과 상이한 유형이 선택된 경우 제출이 거부 될 수 있습니다."
- [ ] 성능 기준:
  - 응답 시간 "입력 후 차량 시스템의 응답 시간이 0.25초를 넘지 않게 하세요." (응답 = 터치 후 터치 효과 애니메이션 발생까지)
  - 앱 실행 10초 이내
  - 콘텐츠 로드 10초 이내
  - 특정 버튼 2초 이내 반응. 2초 내 반응 못 하면 UI로 동작 중임을 알려야 함
- [ ] 백그라운드 복귀 시 마지막 상태 복원 (단, 수 시간 이상 미사용 시 기본 상태 시작 가능)
- [ ] 하드웨어·소프트웨어 손상 및 과점유 금지. 기기 재시작 또는 핵심과 무관한 시스템 설정 변경 제안·요구 금지
- [ ] **Vehicle SDK 퍼미션**: "Vehicle SDK API를 사용하려면 해당 API에 필요한 퍼미션을 앱에 선언해야 합니다." / "Vehicle SDK 퍼미션은 Pleos App Market과 사전 협의 및 승인된 경우에만 선언할 수 있습니다." / "승인되지 않은 퍼미션을 선언한 앱은 심사를 통과할 수 없습니다."
- [ ] 화면 해상도 전환 시 상태 손실·화면 이상 없음, 기능 패리티 유지
- [ ] 레터박스는 한 방향만 미세 보정용으로 허용. 호환성 모드 실행 금지
- [ ] 차량 디스플레이 제원에 맞게 실행 (상세는 Display Layout 가이드, 원문 미수집)

### 1-5. 개인정보 및 보안 (review-user-privacy-security.md)

- [ ] 접근권한은 서비스 필요 범위 내 최소화
- [ ] 고지 항목: 수집 개인정보 항목, 처리 목적, 보유기간, 동의 거부 권리. 명시적 동의 절차 구현 필요
- [ ] 수집 목적·보유기간 구체 기재, 최소 개인정보만 처리, 목적 외 사용 금지
- [ ] 개인정보 처리방침 공개, 열람청구권 등 이용자 권리 보장
- [ ] 위치정보 저장·이용 서비스는 서비스 국가 법률에 따라 등록/신고 내용 확인 요청 가능. 미확인 또는 거짓 증명 시 판매 중단 가능
- [ ] **투명성**: "앱에서 사용자 개인정보에 접근하려 하는 경우, 사용자에게 접근/수집/사용 및 공유에 대해 수집하는 데이터의 목록, 데이터 사용 방식이나 공유 관련 내용을 앱 자체에서 확실하게 명시해야 합니다."
- [ ] **동의**: 개인정보를 활용(접근/수집/사용/공유)하려면 투명성 충족과 사용자 동의 필요. 약관을 App Market에 제출
- [ ] 동의 요구사항:
  - "동의/거부를 선택하는 페이지 또는 팝업 내용은 모호하지 않고, 명확하게 제시되어야 합니다."
  - "제시된 동의 버튼을 누르는 행동 외의 행동을 동의로 간주해서는 안 됩니다. (동의하지 않고 뒤로가기, 화면 내 빈 공간을 터치하기 등)"
  - "사용자가 권한을 허가한 항목의 데이터에만 접근할 수 있습니다."
- [ ] 아동 개인정보: 수집 전 법정 대리인에게 알리고 명시적 동의
- [ ] **사용자 데이터 무단 사용 금지**: "사용자의 동의 없이 무단으로 데이터를 탈취/보관하거나, 사용자 개인 정보를 광고 등에 활용하는 행위, 제3자에게 전송하는 등의 행위는 금지됩니다."
- [ ] **동의 철회 시 처리**: "사용자가 개인정보 제공을 취소한 경우 즉시 앱 내에서 활용 중인 경로를 끊어야하며, 저장된 사용자의 데이터를 삭제해야 합니다." (이 조항은 "이러한 데이터 제공을 사용자가 더이상 원치 않는 경우 취소할 수 있어야합니다" 문맥, 즉 데이터 제공 취소 조항. 법정 보관 의무가 있는 기록에 대한 예외 조항은 문서에 없음)
- [ ] 악성 코드·보안 우회·스팸·DDoS·루팅 등 금지 (보안 위협 및 보안 우회 시도는 발견 시 즉시 거부 가능)

### 1-6. 제출 절차 전 준비 (app-submission-guide.md)

- [ ] 개발자 정보 최신화, 개발자 연락처는 심사팀이 언제든 연락 가능해야 함
- [ ] 기능 테스트: 실행 불가, 크래시, 성능 저하, 버그, 이미지 깨짐, 해상도 늘어짐 없음. 과도한 성능 점유(과부하, 배터리 소모 증가) 주의
  - 성능 가이드: "Pleos Connect 개발자 가이드 > 성능 및 리소스 효율을 고려한 설계 > 메모리·CPU·배터리"
- [ ] 보안 취약점·멀웨어 없음. 참조: "Pleos Connect 개발자 가이드 > 앱 보안 가이드" (원문 미수집)
- [ ] 메타데이터·정보 정확성 확인 (앱 명칭, 버전명, 카테고리, 출시 국가, 연령 등급, 접근 권한, 개인정보 처리 여부, 패키지, 아이콘, 스크린샷, 약관·처리방침)
- [ ] 심사팀이 모든 기능을 확인할 수 있도록 활성화된 계정 제공. 추가 요소 요청 가능
- [ ] **외부 서버 연결 앱은 심사 중 바로 연결되도록 운영 구성 요소를 제출 전에 미리 활성화**: "외부 서버와 연결이 필요한 앱인 경우 심사 중 바로 서비스 연결이 가능하도록 앱 제출 전 앱 운영에 필요한 구성 요소들을 미리 활성화해주시기 바랍니다."
- [ ] 운전자 안전 고려 설계 확인 (상세는 "Pleos Connect 개발자 가이드 > 주행 안전을 고려한 설계" 문서, 원문 미수집)
- [ ] 출시 국가 법률·규제 준수, 허용 증빙 제출
- [ ] 연령 등급 부합: IARC 연계 심의를 거쳐 등급 증적 제출. 한국 게임은 게임물관리위원회 심의 (우리 앱은 게임 아님)
- [ ] 심사 노트에 설명 필요한 기능 주석 + 기능 사용 설명서 첨부

## 2. 앱 제출 절차

### 2-1. 단계

1. 개발자 정보 확인·최신화 (연락처 포함)
2. 앱 테스트: 기능·성능·보안·메타데이터 확인
3. 심사 노트·계정·외부 서버 구성 요소 사전 활성화
4. 차량용 앱 주행 안전 설계 확인 (UI Design Guide, 주행 안전 설계 문서)
5. 출시 국가 규제 확인

## 3. 반려 사유 예시

원문에 "주요 오류 예시"가 있으나 이는 기능 오류 예시이며, 심사 반려 사유 목록(공식 리젝트 코드)은 문서에 없음.

- 인증 키 누락으로 설치 불가
- 설치 후 파일 누락
- 삭제 후 아이콘 또는 저장 공간에 파일 잔존
- 실행 시 강제 종료
- 실행 시 하드웨어 재시작
- 화면 멈춤, 원하는 기능 미동작, 터치·상호작용 미인식
- 사운드 끊김, 그래픽 깨짐
- 승인되지 않은 Vehicle SDK 퍼미션 선언 (심사 통과 불가)
- 제출 아이콘·이미지가 실제 앱과 다름
- 카테고리와 맞지 않는 기능 포함
- 실행 중 심각한 성능 저하 (스터터링, 프레임 저하, 화면 끊김)
- 응답 0.25초 초과, 앱 실행 10초 초과, 콘텐츠 로드 10초 초과, 버튼 2초 초과
- 동의 없는 개인정보 전송, 제3자 전송
- 기기 재시작·핵심과 무관한 시스템 설정 변경 요구
- 개인정보 제공 취소 후 데이터 미삭제
- 메타데이터 악용 (즉시 제외 및 영구 제재 가능)
- 등급 설문 부정확 응답, 등급보다 높은 수위 콘텐츠
- 심사 중 자료 제출 누락 (위치정보 처리방침, 증빙 등): 명시 반려 사유는 아님, 제출 조건으로 기술됨

## 4. 우리 앱 심사 체크리스트

앱: Pleos Connect 차량 내장 앱 "법인 차량 자동 운행기록부". 직원 이름과 운행 위치(출발·도착·목적지) 차량 로컬 DB 저장. 기록 삭제 불가(감사 대응). 국세청 양식 엑셀을 QR 링크로 폰에 전달(외부 서버). 운전자 선택·용무 확인 화면은 P단에서만. 제출물은 release APK.

### 4-1. 통과를 위해 해야 할 일

1. **Vehicle SDK 퍼미션 확인**: Vehicle State 등 사용 API의 퍼미션을 매니페스트에 선언하려면 Pleos App Market과 사전 협의·승인 필요. 승인 전 선언 시 통과 불가. (CLAUDE.md 기준 SDK는 Vehicle State·NaviHelper만 사용 가능)
2. **개인정보처리방침 URL 제출** (필수). 직원 이름, 위치(출발·도착·목적지) 항목별 수집 목적·보유기간·열람권 등 기재
3. **위치정보 이용약관 및 기타 정보 처리방침 URL 제출** (위치정보 활용 시 조건부 필수). 등록 시 "위치정보/GPS" 및 "위치정보 활용" 선택
4. **개인정보 처리 항목 정확 선택**: 수집·저장·전송(외부 서버 전송)·파기 등 모든 과정을 빠짐없이 선택
5. **동의 절차 구현**: 직원 이름·위치 수집 전 명시적 동의. 동의 버튼 외 동작(뒤로가기, 빈 공간 터치)을 동의로 간주하지 않도록 구현. 동의 전 수집 금지
6. **외부 서버 전송 동의 및 고지**: QR 링크 전송 대상(외부 서버), 전송 항목, 제3자 제공 여부를 앱 내에서 명시하고 동의 받음
7. **운전 중 주의 분산**: UI Design Guide 사전 확인. 운전자 선택·용무 확인 화면이 P단에서만 동작하는지 확인하고 주행 중 입력 화면이 뜨지 않도록 설계. 주행 중 화면 표시 기준 수치는 문서에 없음
8. **성능 수치 준수**: 앱 실행 10초, 콘텐츠 로드 10초, 버튼 반응 2초, 응답 0.25초. 2초 넘는 작업은 진행 표시 필요. 백그라운드 복귀 시 상태 복원
9. **심사 노트 작성**: 기능 사용 설명서, 심사 계정(로그인 필요 시 일반 사용자 기준), 외부 서버 연결 구성 요소 미리 활성화
10. **메타데이터**: 앱 제목 30자 이하(영문 기준), 아이콘 512x512 PNG/JPEG 1 MB 이하, 스크린샷 2~8장(기능 사용 전·후 등), 실제 앱과 일치
11. **테스트 데이터 제거**: 더미 데이터·임시 파일·테스트 콘텐츠 제거한 release 빌드
12. **APK 준수**: release APK, 압축 후 600 MB 미만. 서명·타깃 SDK는 문서에 없으므로 Console 또는 별도 확인 필요
13. **고객 지원 정보 1개 이상** (웹사이트·이메일·전화번호). 심사팀 연락 가능 개발자 정보
14. **앱 카테고리 정확히 선택**. 기능 목적(운행기록)에 맞는 카테고리
15. **연령 등급**: 우리 앱은 일반 사용자 대상으로 등급 설문 정직하게 응답. 미디어 콘텐츠 없음 (문서에 "미디어 앱" 정의는 동영상·게임·브라우저)

### 4-2. 위험 항목 (5줄 이내 요약에 사용)

1. **삭제 불가 데이터 vs 삭제 요구**: 원문은 "사용자가 개인정보 제공을 취소한 경우 ... 저장된 사용자의 데이터를 삭제해야 합니다"라고 함. 감사용 운행기록 보관 의무 예외는 문서에 없음. 직원 이름·위치가 삭제 불가로 설계되어 있으면 반려 또는 재심사 위험. 보유기간 고지 및 보관 근거 명시 필요.
2. **위치정보 동의와 처리방침**: 위치정보 저장·이용 서비스는 등록·신고 내용 확인 요청 가능, 확인 못 하면 판매 중단 가능. 위치정보 이용약관 URL 조건부 필수.
3. **외부 서버 전송(QR 링크)**: "제3자에게 전송하는 등의 행위는 금지" 조항 및 제3자 제공 고지·동의 필요. 외부 서버 구성 요소를 심사 전 활성화해야 함. 전송 동의 절차 누락 시 반려 위험.
4. **Vehicle SDK 퍼미션 미승인**: 승인되지 않은 퍼미션 선언 시 통과 불가. 승인 상태를 제출 전 확인해야 함.
5. **주행 중 주의 분산 판단 기준 불명확**: 미디어 앱 조항만 명시. 운전자 선택·용무 확인 화면 P단 제한 여부는 UI Design Guide(원문 미수집)로 확인 필요. 앱 특성상 심사 단계 추가 위험 판단 시 등록 거부 가능.
